# DataStructures 📚

Welcome to my repository for the Data Structures course at AUA. This repo contains the implementations of fundamental algorithms and data structures discussed in class.

---

## Repository Structure

The code is organized by topic for easier navigation:

*   **[`Sorting`](src/main/java/am/aua/Sorting/README.md)**: Contains various sorting algorithms and performance benchmarks.
*   **[`LinkedLists`](src/main/java/am/aua/LinkedLists/README.md)**: Contains implementations of Singly, Doubly, and Circular linked lists.
*   **[`Stack`](src/main/java/am/aua/Stack/README.md)**: Contains implementations of Stack using Arrays and Linked Lists.
*   **[`Queue`](src/main/java/am/aua/Queue/README.md)**: Contains implementations of Queue, Deque and Circular Queue.
*   **[`List`](src/main/java/am/aua/List/README.md)**: Contains implementations of `ArrayList`.
*   **[`PositionalList`](src/main/java/am/aua/PositionalList/README.md)**: Contains implementations of `PositionalList` (handles/cursors approach).


*   **`src/main/java/am/aua/homeworks/`**: Each homework package contains its homework question and my solutions.

## How to Use This Repo

### For Quick Review
If you're cramming before a quiz, focus on the `README.md` files located in each subdirectory. They contain:
*   **Concepts:** Short, high-level summaries of how the structure works.
*   **Cheat Sheets:** Visualizations or tables comparing complexity and use cases.
*   **Benchmarks:** Real-world performance results (specifically in the Sorting directory).

### For Detailed Viewing
If you want to understand *how* it's actually built:
1.  **Javadoc Comments:** Every class file (e.g., `Bubble.java`, `SinglyLinkedList.java`) is documented. Read the Javadoc headers—I've laid out the algorithm logic step-by-step.
2.  **Implementation:** Look directly at the method bodies. I've kept them clean so you can see exactly how the pointers or indices are manipulated.

### Tips
*   **Testing:** Use the provided `Main.java` files within each directory as a starting point to test the methods.

*Happy coding and learning, and try not to mess up the midterms.* 😊
